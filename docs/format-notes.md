# 横浜市様式「従業者の勤務の体制及び勤務形態一覧表」調査メモ

出典: 横浜市 [勤務形態一覧表様式・料金表作成例【地域密着型サービス】](https://www.city.yokohama.lg.jp/business/bunyabetsu/fukushi-kaigo/kaigo/shinsei/service/kinmu.html)
（地域密着型通所介護用: `78_kinmuhyo_202607.xlsx`）

## シートの構成（グラウンドアップの実運用ファイル シフト2026.xlsx）

- `9月1` / `9月2`, `8月1` / `8月2` … 実際に作成・提出した月次シフト表。
  **`◯月1` = 午前（1単位目）、`◯月2` = 午後（2単位目）**。
  この施設は「サービス提供単位数＝2」（午前クラスと午後クラスを別々に運営）のため、
  横浜市への提出上、午前・午後で別々の勤務形態一覧表を作成する必要がある。
- `シフト記号表（勤務時間帯）` … a〜z等のシフト記号と、始業・終業・休憩・勤務時間数、
  サービス提供時間内の勤務時間数の対応表。**要提出**（メインの一覧表とセットで出す）。
- `記入方法` … 横浜市が配布する記入マニュアル（提出不要、参照用）。
- `【記載例】...` … 記入例（提出不要）。

## 勤務形態一覧表シートのセル構造

- `AC2` = 年（西暦）, `AG2` = 月
- `BB6` = 常勤が勤務すべき時間数（週）, `BB8` = 当月の日数（`=DAY(EOMONTH(DATE(AC2,AG2,1),0))` という数式で年月から自動計算）
- `BB10`〜`BB15` = サービス提供単位数・何単位目か・サービス提供時間
- 日付ヘッダー: 22行目=日付（1〜31）, 23行目=月内の曜日カウンタ, 24行目=曜日（月火水木金土日）
  列は **S列(19列目)を1日目** として1日1列、最大 AW列（31日目）まで。
- スタッフ1人につき3行1組（例: 25〜27行目）
  - 1行目: `B`=No, `C`=職種, `G`=勤務形態記号(A/B/C/D), `H`=資格, `L`=氏名,
    日付列に**シフト記号**（a, b, c…）を直接入力
  - 2行目: `P`列ラベル「勤務時間数」。日付列は数式
    `=IF(S25="","",VLOOKUP(S25,'シフト記号表（勤務時間帯）'!$C$6:$K$35,9,FALSE))`
    でシフト記号表から自動計算。`AX`列=月合計、`AZ`列=週平均。
  - 3行目: `P`列ラベル「サービス提供時間内の勤務時間数」。同様にVLOOKUPで自動計算（列19番目）。
- **つまり実際に人手で入力するのは「シフト記号」1行だけ**で、時間数・合計・週平均はすべて
  シートの数式が自動計算する。自動化の本丸は「どの日にどのスタッフに何のシフト記号を
  割り当てるか」を決めること。
- 80〜84行目は「（参考）1日の職種別人員内訳」の集計行（スタッフ行ではない）:
  80=生活相談員, 81=看護職員, 82=介護職員, 83=機能訓練指導員, 84=Total。各セルは
  `=IF($L80="","",IF(COUNTIFS($F$25:$F$72,$L80,S$25:S$72,">0")=0,"",COUNTIFS(...)))`
  という形のCOUNTIFSで、F列（3行目=「サービス提供時間内の勤務時間数」の行にだけ
  `=C{記号行}`で職種名が入る）とS列（同じ行＝サービス提供時間内の勤務時間数の値）を
  条件に、「その職種で、かつその日のサービス提供時間内の勤務時間数が0より大きい」
  行だけを数える。Total（84行目）は `=SUM(S80:S83)` で、**生活相談員・看護職員・
  介護職員・機能訓練指導員の4職種だけの合計**（**管理者・送迎職員はそもそも
  L80:L83に含まれず、集計対象外**）。
  ⚠️ **重大な実装バグの教訓**: スタッフ行を氏名（L列）の有無で判定するループの
  終了条件が甘いと（`r < 83` など）、80行目（L80="生活相談員"で氏名的な値に
  見えてしまう）まで「スタッフ行」と誤認してシフト記号クリア処理が走り、
  80行目のCOUNTIFS数式そのものを消してしまう。実際にこのバグで生成後の
  Totalが過小集計される事故があった（2026-09、`generate_shift.py` v2で修正）。
  スタッフ行のスキャン・クリアは必ず `STAFF_ROWS_END = 80` 未満に収めること。

## 勤務形態（G列）の記号（`記入方法`シートより）

| 記号 | 区分 |
|---|---|
| A | 常勤で専従 |
| B | 常勤で兼務 |
| C | 非常勤で専従 |
| D | 非常勤で兼務 |

常勤/非常勤の判定は「その事業所の常勤が勤務すべき時間数（BB6, 週40時間など）に達しているか」
であり、雇用形態（正社員/パート）そのものではない。専従/兼務は「1つの職種のみに従事＝専従、
複数の職種を兼務＝兼務」。

## シフト記号表の中身（`shift_codes.csv` に抽出済み）

- a〜i: 始業・終業・休憩から勤務時間数を計算する通常のシフト（例: a = 8:30〜12:30 休憩なし = 4.0時間）
- j, k, n〜s: 未使用（記号だけ予約されている）
- 有 / 有休: 有休用の記号。始業・終業等は通常のシフトと同じ時間を入れるが、
  横浜市の指示では「有休のシフト記号を作る場合は始業・終業・休憩・開始・終了はすべて0:00にする」
  という注意書きもある（現状の運用では時間を入れているため、要確認・要相談）。
- u〜z: 時刻ではなく時間数を直接入力するための記号（「○：○○〜○：○○」の形で書けない場合用）

## グラウンドアップの「シフト作成の手順」（ユーザー作成、`作成手順`シートより）

1. リセット作業
   - 月を変更する
   - 常勤スタッフの日曜以外を一旦出勤にする（1人作成したらコピペ）
   - パートスタッフの固定曜日を一旦出勤にする（ひな形からコピペで作成）
2. 休み希望をそのまま反映する（常勤・パートとも）
3. 常勤は所定勤務日数に合わせる
4. 足りない日の調整

## v2スクリプトでの実装方針

- ステップ1・2を自動化（`generate_shift.py`）。既存の月シート（例: `9月1`）を
  `openpyxl.copy_worksheet()` で複製し、日付ヘッダーを対象月に書き換えたうえで、
  スタッフごとにシフト記号だけを書き込む。数式・書式は複製元からそのまま引き継がれる
  ので、Excelで開けば時間数・合計は自動計算される。
- 「営業日」（スタッフに勤務させて良い日）は、日曜と固定休業期間
  （`FIXED_CLOSURE_MD`: 5/3-5, 8/13-15, 12/30-31, 1/1-3）を除いた日。常勤の
  所定勤務日数計算（jpholidayベースの祝日カウント）とは別概念（README参照）。
- ステップ3も自動化した（`process_unit()`）。
  - パート: 固定曜日パターン＋`available`（勤務可能）希望を、営業日の範囲で
    そのまま反映する（`default_pattern_for_part_time()`）。
  - 常勤: 氏名単位でグループ化（`ft_groups_by_name`）し、`available`希望の日を
    先に組み込んだうえで、実質所定日数（`full_time_target_days()` − 有休日数）に
    対する不足分を、その時点で配置人数が最も少ない営業日から**ラウンドロビン**で
    埋めていく（`allocate_full_time_groups()`）。全員を1人ずつ順番に1日ずつ
    埋めることで、特定の常勤スタッフだけが手薄な日に集中しないようにしている。
    6日以上の連続勤務になる候補日は基本スキップし（`max_consecutive_run()`）、
    本当に他に候補がない場合のみ許容して `run_violation` フラグを立てる。
  - 兼務者（上口さんの管理者/生活相談員など）は氏名単位でグループ化して
    **同じ日に揃えて**出勤日を割り当てるため、2行の勤務日がずれる事故は起きない。
- ステップ4も自動化した。Total（配置人数）が4人未満の営業日は、
  `available`希望のあるスタッフを既に組み込んだ後の結果で判定し、それでも
  4人未満なら赤強調＋レポート警告のみ（自動ではそれ以上人を追加しない＝安全側）。
  6人超の日は参考情報として一覧表示するのみで自動では減らさない。
- 完成後、`review_unit()` が独立に全体をもう一度チェックする（所定日数一致・
  Total4〜6人・連続勤務6日未満・兼務者の勤務日一致・staff_master.csvとの
  対応漏れの5項目）。「レビューして直してもう一度チェックする」という
  ユーザーの要望に対応するため、生成ロジックとは別の集計経路で検証している。

### Total集計のよくある落とし穴（重要）

「Total」は単純な出勤人数ではない。以下の2つを両方満たす行だけがカウントされる：
(1) 職種がL80:L83の4職種（生活相談員・看護職員・介護職員・機能訓練指導員）に
含まれること（管理者・送迎職員は対象外）、(2) その日のシフト記号の
「サービス提供時間内の勤務時間数」が0より大きいこと（管理者の事務作業記号`b`は
常に0になるため、`b`で出勤していてもカウントされない）。`counts_toward_total()`
がこれを再現しており、LibreOfficeでの実際の数式再計算結果と完全一致することを
2026年10月データで確認済み。今後シフト記号やスタッフの職種構成を変える場合は、
この2条件が変わっていないか要確認。
