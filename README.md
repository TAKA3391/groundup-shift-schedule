# グラウンドアップ シフト表 自動生成

リハビリスタジオ グラウンドアップの毎月のシフト表作成を自動化するプロジェクトです。
横浜市 地域密着型通所介護の監査提出様式「従業者の勤務の体制及び勤務形態一覧表」に
沿った形式で、Excelファイル（午前シート・午後シートの2枚）を出力します。

## 現状（v1でできること・できないこと）

現在のシフト作成は、ご本人の「作成手順」によると次の4ステップです。

1. リセット作業（月を変更し、常勤は日曜以外を一旦出勤に、パートは固定曜日を出勤にする）
2. 休み希望をそのまま反映する
3. 常勤は所定勤務日数に合わせる
4. 足りない日の調整

**v1で自動化した範囲：ステップ1・2**
ステップ3・4は「人手による最終判断が必要な部分」（何人配置すれば安全か、誰に日数を寄せるか）
のため、v1では自動化せず、代わりに人数・日数のサマリーレポートを出力して、
判断しやすくすることに留めています。今後、実際に使ってみたフィードバックをもとに
ステップ3・4の自動化も磨いていく想定です。

## ファイル構成

```
shift_codes.csv       シフト記号表（a〜z, 有など）の時間定義（横浜市様式の「シフト記号表」シートから抽出）
staff_master.csv       スタッフ一覧（職種・勤務形態・資格・パートの固定曜日・既定のシフト記号）
generate_shift.py      シフト表生成スクリプト（v1: ステップ1・2を自動化）
シフト2026.xlsx         横浜市様式 + 実績データが入ったベースファイル（8月・9月分）
output/                生成したシフト表と、日別・スタッフ別サマリーレポートの出力先
docs/format-notes.md   横浜市様式の構造・数式・用語の調査メモ
```

## staff_master.csv で毎月確認・更新すること

- `fixed_weekdays` … パートさんの固定勤務曜日（例: `火,木,土`）。**現在は空欄です。
  実際の固定曜日を確認して埋めてください**（過去の実績には休み希望反映後の変則的な
  出勤日が混ざっているため、実績から自動推定していません）。
- `default_code_am` / `default_code_pm` … その人がいつも使うシフト記号。複数の記号を
  使い分けている人（永田さんのd/eなど）は要確認。
- `target_days_per_month` … 常勤スタッフの所定勤務日数（わかれば入力。ステップ3の
  自動化を進める際に使います）。
- 新しいスタッフが入ったら行を追加、辞めたスタッフは行を削除してください。

## 使い方

```bash
pip install openpyxl

python3 generate_shift.py \
  --base シフト2026.xlsx \
  --source-am "9月1" --source-pm "9月2" \
  --year 2026 --month 12 \
  --staff staff_master.csv \
  --requests requests_202612.csv \
  --out output/シフト2026_12月_案.xlsx
```

`--requests` は休み希望のCSV（省略可）。形式:

```
name,date,status
上口由佳,2026-12-21,off
織田陽子,2026-12-24,paid_leave
永田千尋,2026-12-05,am_only
```

- `off` … その日は休み
- `paid_leave` … 有休（休みとして扱う。給与処理は別途）
- `am_only` … 午前のみ出勤可（午後シートからは外す）
- `pm_only` … 午後のみ出勤可（午前シートからは外す）

実行すると `output/` に

- `シフト2026_12月_案.xlsx` … 「12月1」「12月2」シートが追加された案（Excelで開くと
  自動的に勤務時間数・職種別人員内訳が計算されます）
- `シフト2026_12月_案_report.txt` … スタッフ別の稼働日数、日別・職種別の配置人数

が出力されます。案をExcelで開いて内容を確認・修正してから、監査保存用として保管してください。

## 監査保存について

横浜市の地域密着型通所介護では、勤務形態一覧表の保存義務があります。生成したExcelは
`output/` に残るので、月ごとにファイル名を変えて（例: `シフト2026_12月.xlsx`）GitHubに
コミットしておけば、変更履歴つきで保管できます。
