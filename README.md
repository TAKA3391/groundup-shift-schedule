# グラウンドアップ シフト表 自動生成

リハビリスタジオ グラウンドアップの毎月のシフト表作成を自動化するプロジェクトです。
横浜市 地域密着型通所介護の監査提出様式「従業者の勤務の体制及び勤務形態一覧表」に
沿った形式で、Excelファイル（午前シート・午後シートの2枚）を出力します。

## 現状（v1.2でできること・できないこと）

現在のシフト作成は、ご本人の「作成手順」によると次の4ステップです。

1. リセット作業（月を変更し、常勤は日曜以外を一旦出勤に、パートは固定曜日を出勤にする）
2. 休み希望をそのまま反映する
3. 常勤は所定勤務日数に合わせる
4. 足りない日の調整

**v1.2で自動化した範囲：ステップ1〜3**
ステップ3（常勤スタッフの所定勤務日数への調整）は、休み希望を反映した結果 所定日数
（有休分を除いた実質所定日数）に足りないスタッフがいれば、その時点で最も配置人数の
少ない土曜日から順に出勤日を自動追加する形で自動化しています（詳細は下記）。
ステップ4（最低人員基準を満たすための最終確認）は「何人配置すれば安全か」という
現場判断が必要な部分のため、引き続き自動化せず、日別・職種別の配置人数レポートを
出力して判断しやすくすることに留めています。

## 常勤スタッフの所定勤務日数（ユーザー確定ルール、2026-10時点）

事業所は日曜以外営業。常勤は「土日祝日の日数分」休みを取る（土曜や祝日に出た分は
別の平日で調整して帳尻を合わせる）。

```
所定勤務日数 = その月の日数 - (土曜日数 + 日曜日数 + 祝日日数)
所定勤務時間 = 所定勤務日数 × 8時間
```

例: 2026年10月は31日中、土日祝日が10日（土5・日4・祝1）なので所定21日・168時間。
`generate_shift.py` の既定パターン（ステップ1）は「土日祝日以外の平日は全出勤」に
なっており、これだけで所定日数と一致するよう設計されています（2026年10月で確認済み）。

休み希望を反映すると所定日数を下回ることがありますが、これは**ステップ3として自動で
調整されます**：不足しているスタッフについて、その時点で1日あたりの配置人数が最も
少ない土曜日から順に出勤日を追加していきます（`process_unit()` のPass 2）。それでも
候補日が足りず不足が残る場合のみ、`..._report.txt` に警告として出ます。

**有給休暇は「所定日数」とは別枠で休みとして扱います。** 休み希望に `paid_leave` が
ある場合、その日数分だけ実質的な所定勤務日数を差し引いて（例: 所定21日・有休1日なら
実質所定20日）、ステップ3の自動調整はその実質所定日数に合わせます。公休（土日祝日）の
調整とは別物として扱われるため、有休を取っても他の平日で「埋め合わせ」を強制されません。
レポートには「実質所定N日（うち有休N日を除く）」の形で表示されます。

常勤スタッフ: 上口由佳、板倉芽生、山田恵美、高山岳、宮路愛
パートスタッフ: それ以外（永田、鷹野、若尾、大野、織田、藤田、金上）

※ 島倉一成さんは2026年10月時点で退職済みのため `staff_master.csv` から削除済みです。

## ファイル構成

```
shift_codes.csv       シフト記号表（a〜z, 有など）の時間定義（横浜市様式の「シフト記号表」シートから抽出）
staff_master.csv       スタッフ一覧（職種・勤務形態・資格・パートの固定曜日・既定のシフト記号）
generate_shift.py      シフト表生成スクリプト（v1: ステップ1・2を自動化）
シフト2026.xlsx         横浜市様式 + 実績データが入ったベースファイル（8月・9月分）
output/                生成したシフト表と、日別・スタッフ別サマリーレポートの出力先
docs/format-notes.md   横浜市様式の構造・数式・用語の調査メモ
```

## staff_master.csv で毎月確認・更新すること

- `fixed_weekdays_am` / `fixed_weekdays_pm` … パートさんの固定勤務曜日（例: `火,木,土`）。
  午前・午後で曜日が異なる人がいる（例: 大野さんは土曜AMのみ、若尾さんは土曜PMのみ）ため
  2列に分かれています。**両方空欄のスタッフ（織田さん・藤田さんなど）は「不定期勤務」
  として自動生成の対象外になり、手作業での入力が必要です**（意図的な仕様）。
- `default_code_am` / `default_code_pm` … その人がいつも使うシフト記号。複数の記号を
  使い分けている人（永田さんのd/eなど）は要確認。
- 常勤（keitai A/B）は `fixed_weekdays_*` 不要。所定勤務日数は自動計算されます
  （上記「常勤スタッフの所定勤務日数」参照）。
- 新しいスタッフが入ったら行を追加、辞めたスタッフは行を削除してください。
- 同じ人が複数の職種を兼務している場合（上口さん＝管理者+生活相談員など）は、
  役割ごとに行を分けて登録してください。スクリプトは氏名と職種（シートのC列）の
  組み合わせでマッチングします。

## 使い方

```bash
pip install openpyxl

python3 generate_shift.py \
  --base シフト2026.xlsx \
  --source-am "9月1" --source-pm "9月2" \
  --year 2026 --month 12 \
  --staff staff_master.csv \
  --requests requests_202612.csv \
  --out output/シフト2026_12月_案.xlsx
```

`--requests` は休み希望のCSV（省略可）。形式:

```
name,date,status
上口由佳,2026-12-21,off
織田陽子,2026-12-24,paid_leave
永田千尋,2026-12-05,am_only
```

- `off` … その日は休み
- `paid_leave` … 有休（休みとして扱う。給与処理は別途）
- `am_only` … 午前のみ出勤可（午後シートからは外す）
- `pm_only` … 午後のみ出勤可（午前シートからは外す）

実行すると `output/` に

- `シフト2026_12月_案.xlsx` … 「12月1」「12月2」シートが追加された案（Excelで開くと
  自動的に勤務時間数・職種別人員内訳が計算されます）
- `シフト2026_12月_案_report.txt` … スタッフ別の稼働日数、日別・職種別の配置人数

が出力されます。案をExcelで開いて内容を確認・修正してから、監査保存用として保管してください。

## 監査保存について

横浜市の地域密着型通所介護では、勤務形態一覧表の保存義務があります。生成したExcelは
`output/` に残るので、月ごとにファイル名を変えて（例: `シフト2026_12月.xlsx`）GitHubに
コミットしておけば、変更履歴つきで保管できます。
